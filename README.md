# Hey, I'm Romain

Software engineer who enjoys building products from scratch — mobile apps, web platforms, and everything in between. Lately I also distribute them: I build the tool, write the pages, and record the videos that send people there.

## What I'm working on

**[Capineo](https://capineo.com)** — Investing documented with real numbers, losses included. A YouTube channel ([@CapineoFR](https://www.youtube.com/@CapineoFR)) and a site that publishes my own brokerage statements: what I paid in, what I earned, and the line that is down 38%. Astro on Cloudflare, no third-party script — traffic is measured server-side instead.

**[Wallet Simulator](https://wallet-simulator.com)** — Capineo's tool. Compose a multi-asset portfolio (ETFs, crypto, commodities) and replay it against real historical data. Next.js, Supabase and Upstash Redis. Its backtesting engine was audited error by error against hand-computed scenarios — a simulator that invents a drawdown would destroy the one thing the channel is built on.

**[Crux](https://github.com/romainpml/crux-mobile-app)** — A Wordle-style daily word game in French with leagues and competitive rankings. Monorepo with a Fastify API, Expo/React Native mobile app, and shared Zod contracts.

**[kcal](https://github.com/romainpml/kcal-mobile-app)** — Mobile calorie & fitness tracker with barcode scanning, AI-powered plate recognition (Claude Vision), recipes, weight tracking, and intermittent fasting timer. Built with Expo and OP-SQLite.

**[PartyBox](https://github.com/romainpml/party-box)** — Sixteen French party games in one phone app: Times Up, Undercover, Action ou Vérité, Cadavre exquis and more. Expo and React Native.
